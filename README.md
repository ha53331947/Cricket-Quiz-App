# 🏏 Cricket Quiz App

A sleek, modern Cricket Quiz mobile application built with **React Native (Expo)** and **Supabase**. Test your cricket knowledge with interactive quizzes, real-time score tracking, and user authentication.

## ✨ Features
- **Interactive Cricket Quizzes:** Engaging questions covering international and domestic cricket.
- **User Authentication:** Secure sign-up and login powered by Supabase Auth.
- **Real-Time Backend:** Fast and reliable data fetching using Supabase (PostgreSQL).
- **Modern Dark UI:** Clean, responsive interface designed with a dark aesthetic.

## 🛠️ Tech Stack
- **Frontend:** React Native, Expo
- **Backend & Auth:** Supabase
- **Local Storage:** AsyncStorage
